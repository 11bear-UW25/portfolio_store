# 自炊献立の栄養価シミュレーター

meal-nutrition-simulator

## アプリ概要

Next.jsとSupabaseを用いた、自炊献立の栄養価をシミュレーションできるアプリです。

日付ごとに朝食・昼食・おやつ・夕食の料理名と、使用食材・使用量（g）を入力すると、以下の6種類の栄養価を自動計算します。
- エネルギー
- たんぱく質
- 脂質
- 炭水化物
- 食物繊維
- 食塩相当量

食事別・1日全体の栄養価を確認できるほか、作成した献立の保存・編集・削除や、過去の献立の再利用にも対応しています。

## 目的

毎日の献立を考える際に、使用する食品とその量によって栄養価がどのように変化するかを、簡単に確認できることを目指しました。

## 機能一覧
### 1.食材一覧取得

- Supabaseに登録された食品データ取得
- 登録済み食品36品目から選択
- 各食品の100g当たりの栄養価を計算に使用

### 2.献立作成・管理（CRUD）

- 日付ごとに献立を新規作成
- 作成した献立をSupabaseに保存
- 保存済み献立を読み込み・表示
- 料理名・食品・使用量の編集
- 料理・食品の削除
- 献立全体の削除
- ページを再読み込みしても保存内容を保持

### 3.食事・料理の登録

- 朝食・昼食・おやつ・夕食の4区分に対応
- 食事区分ごとに複数の料理を登録
- 料理ごとに複数の食品と使用量（g）を登録
- 食品の使用量を変更すると栄養価を自動で再計算

### 4.栄養価計算（本アプリのメイン機能）

各食品について、次の式で栄養価を計算します。

***栄養価 ＝ 100g当たりの栄養価 × 使用量（g）÷ 100***

- エネルギー・たんぱく質・脂質・炭水化物・食物繊維・食塩相当量を計算
- 複数食品・複数料理の栄養価を合算
- 食事別・1日全体の表示切り替え
- 食品の使用量変更に応じた自動再計算

### 5.週間カレンダー・献立表示

- 週間カレンダーで日付ごとの献立を確認
- 日付を選択して献立の詳細を表示
- 前週・翌週への移動
- 保存済みの料理名をカレンダーに表示
- 日付ごとに献立を管理

### 6.献立再利用
- 保存済みの献立を別の日付へコピー
- 料理名・食事区分・食品・使用量を複製
- コピー先で編集してから保存
- コピー元の献立は変更せず保持
- コピー先に既存の献立がある場合は上書きを確認

### 7.認証・データ管理

- Supabaseの匿名認証を使用
- ログイン操作なしで献立を作成・保存
- 匿名セッションを再利用
- RLSにより、ユーザーごとの献立データを分離
- Supabase RPCによる献立データの一括保存・削除

### 8.エラー処理・入力チェック

- 未入力や不正な使用量の保存を防止
